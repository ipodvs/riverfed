The system

One engine. Many ways to organise knowledge.

The Karpathy teach-back wiki is one shipped model, not the whole product. Second Brain turns captured knowledge into projects and areas. SOPs-to-Skills turns operational knowledge into instructions agents can execute. Each model shares the same capture, governance, and output engine.

New agent practices can be added as model manifests. The Studio discovers them without a page or server rewrite.

Questions

What you might be wondering.

What does “automatic” actually mean?

A small Python server runs on localhost. Drop a file in the web UI and click Convert, then click Ingest pending. The Studio handles transcript extraction, wiki updates, deck generation, diagram generation, and Word export. No manual editing is required. Every artefact is plain Markdown or JSON, so you can still edit anything by hand.

Does it work offline?

Conversion and rendering work entirely offline. The ingest step runs on your local agent CLI through Claude Code (Anthropic) or Codex (OpenAI), billed to that subscription. There's no third-party SaaS in the loop.

Which AI subscription do I need?

Either. The whole pipeline runs on the agent CLI you already pay for: Claude Code with a Claude.ai Pro/Max subscription, or Codex with a ChatGPT plan. The Agent selector picks automatically (Claude Code first, Codex as fallback), or you can pin one explicitly. An explicit pick fails with the exact login command rather than silently switching. No API keys, no pay-per-token.

Is Karpathy the only knowledge model?

No. It is one model for building a teach-back wiki from sources, topics, entities, and concepts. Second Brain (PARA) organises knowledge around action. SOPs-to-Skills compiles procedures into instructions for agents. The registry is open, so new research and operating practices can become reusable models without changing the core pipeline.

Marp or PowerPoint?

Both. The Marp pipeline gives you a Markdown source that diffs in git and that agents can edit. The Studio auto-renders it to HTML, PDF, and PPTX on every run. The native PPTX renderer builds a real editable PowerPoint with 13 designed slide types. Every shape, text box, and icon is hand-editable. Use Marp for diff-able source-of-truth decks; use native PPTX when you want to hand off a .pptx someone will actually edit in PowerPoint.

Can I customise the look?

Yes. The Studio's design picker ships with Riverfed, Heritage, and Aurora: three full palettes + typography sets. Edit any of them in the browser (colour pickers + font fields + live preview) or create a new one from scratch. Edits save as designs/custom/<id>.md following the DESIGN.md spec. Reset to default at any time. The chosen design's tokens flow into the renderer so every generated artefact uses the same palette.

What about whiteboard / Excalidraw videos?

Chapter-start frames usually catch the canvas while it's still blank. The --dense-until mode samples a frame every 45 seconds for the first 20 minutes (configurable) and auto-flags each one as vision-relevant. The ingest agent then reads each flagged JPEG as an image (not just the OCR text: Excalidraw text reliably OCRs to gibberish) and extracts the structural diagrams. The wiki source page gets a ## Visual architecture section citing each frame's timestamp.

What generators ship today, and what’s next?

Live now: Marp decks (auto-rendered to HTML/PDF/PPTX), native editable PowerPoint (13 slide types), Excalidraw diagrams, speaker manuals (markdown + styled Word doc), Anki flashcard decks for spaced repetition, an agent skill library compiler (SOPs in, executable SKILL.md + AGENTS.md out), plus a design picker that styles all of them. Next on the roadmap: Notion exports, podcast scripts, social-card carousels, handouts. Each new generator reads the same wiki: add one, get a new output across your whole knowledge base.

Who's it for?

Builders, founders, researchers, and lifelong learners. Anyone who consumes more knowledge than they can recall and wants that consumption to start working for them. It is especially useful if you teach, present, or write because the deck and speaker manual save days.
