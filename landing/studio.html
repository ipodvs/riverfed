Marp deck

Generate a slide deck

The agent reads the wiki + wiki/training/design.md and emits Marp markdown. ~2–5 minutes per deck. Output lands in wiki/training/studio/.

Excalidraw

Generate a diagram

The agent reads the wiki + the Excalidraw conventions in design.md and emits a brand-coloured .excalidraw file. Drag into excalidraw.com to view. Output lands in diagrams/studio/.

Native PowerPoint

Generate an editable .pptx

The agent reads the wiki and emits structured slide JSON; Python renders it to a native PowerPoint file with real editable text boxes (not Marp's flattened export). Tier 1 layouts: cover, lead, section, content, KPI, quote. ~2–5 min per deck. Output lands in wiki/training/studio/<name>.pptx.

For richer layouts (versus panels, six-up grids, cards), use the Marp deck above. It has the full component library.

Anki Flashcards

Generate a flashcard deck

The agent reads the base and authors atomic question/answer cards (grounded in the pages, source slugs cited), then Python packages them as a real .apkg for direct import into Anki desktop or mobile. Regenerating the same deck updates it in Anki instead of duplicating. Output lands in wiki/training/studio/anki/.

Agent Skills

Compile an agent skill library

The agent reads the selected base and emits one SKILL.md per procedure or runbook in this repo's house skill format (trigger-rich description, workflow with the why, gotchas, references back to the base), plus a library README.md and an agents.md context file. Works best on a SOPs to Skills base (drop your ops docs on the Convert page first). Output lands in wiki/training/studio/skills/<base>/. Copy the .claude/ folder into any repo to install.
