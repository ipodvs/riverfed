# Branding rules — name, Sith Red, nav order, brand mark

## The rule

Four critical brand constraints (the full system lives in
`wiki/training/design.md`):

- **Product name** is **Riverfed**, in copy and identifiers alike —
  don't reintroduce older working names.
- **Sith Red rule**: red (`#ff4d4d` / `--saber-red` / `--united`) is
  reserved for errors and destructive actions. Never use it as a
  decorative card accent; use orange/yellow for differentiation.
- **Nav order across all pages**: Add · Knowledge · About ·
  [Create CTA → /studio]. Renamed 2026-07-22 (Convert→Add,
  Wiki→Knowledge); Studio dropped as a text link, reached via the
  Create CTA only. Routes/filenames unchanged.
- **Top-left brand**: 38×38 logo (currentColor via CSS mask) +
  "Riverfed" wordmark, gap 8 px.

## Why it exists

Keeps every surface (landing, decks, diagrams, UI) visually and
verbally consistent, and keeps red unambiguous as a danger signal
(contributing-to-riverfed).

## Scope & exceptions

All user-facing surfaces: pages, decks, diagrams, icons, copy — and
the identifiers behind them (repo slug `riverfed`, env vars, folders).

Respected by: [[update-a-deck-or-diagram]].
