# File naming — kebab-case content, snake_case Python

## The rule

- Pages, slides, decks, diagrams: kebab-case slugs (`my-new-deck.md`,
  `agent-loop.excalidraw`).
- Python scripts: snake_case (`promote_backlog.py`, `studio_marp.py`).
- HTML pages: kebab-case (`studio.html`, `wiki.html`).
- Icons: kebab-case verbs/nouns (`folder-spark.svg`,
  `layers-stack.svg`).

## Why it exists

Predictable names keep slugs, wikilinks, and script invocations
guessable without looking anything up
(contributing-to-riverfed).

## Scope & exceptions

Every new file in the repo. No exceptions stated.

Respected by: [[hand-edit-wiki-pages]], [[update-a-deck-or-diagram]].
